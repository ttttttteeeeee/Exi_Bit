# Mini Platformer Demo

This is a standalone browser demo for Exi_Bit. It is intentionally kept separate from the planned Python/Pygame engine because this prototype uses HTML, CSS, and JavaScript rather than Python.

## Run locally

1. Open `index.html` in Chrome, Edge, or Firefox.
2. Click **Start game**.
3. Use **Left/Right** or **A/D** to move, **Space/Up** to jump, **R** to restart, and **Esc** to pause.

No build step, package installation, server, or internet connection is required.

## Important

This demo proves a playable platformer concept. It does **not** implement or use Exi_Bit's Python engine modules. When the Python engine is built, its reusable game loop, input, physics, renderer, and world systems should live in the `exi_bit/` package; this folder should remain an example/demo only.
